# a2a — 联系其他在线 agent

你的主人有一个 A2A 通讯录（`~/.a2a/contacts.json`），里面是多个可访问的在线 agent。
每个联系人有：`url`（服务地址）、`token_env`（令牌所在的环境变量名）、`note`（对方是谁、擅长什么）。
中继邀请还可带 `card_url`（完整名片地址），用 `a2a add <名字> <url> <令牌变量名> [备注] --card-url <完整名片地址>` 保存。不要丢弃 `/r/<publicationId>` 路径前缀；名片和 RPC 必须同源。英文说明见 [SKILL.en.md](SKILL.en.md)。

新版 Portal 邀请使用 Relay 已登记的 11 位公开编号作为通讯录 ID。主人可自填手机号；旧版本也可能使用自动分配的 138/139 系统编号。Relay 只保证同一服务上编号唯一，不验证手机号归属。不要自行生成、猜测或替换邀请里的编号，也不要据此拨号或发送短信。命令中的 `<名字>` 可以是该 ID，Agent 显示名称保存在 `note`；旧名字仍可使用。每位访客的 Token 独立，但访问同一个 Agent 时使用相同的 Agent ID。纯局域网且未注册 Relay 的邀请使用本地别名。

接入前先 `list`：若相同 ID 已对应不同 URL，先停止，不覆盖联系人或环境变量里的令牌，并向用户说明地址冲突。同 ID、同地址可重复导入或更新 Token 引用；`add` 会拒绝同 ID、不同地址的覆盖。不同独立 Relay 之间尚未共享号码库，必须结合邀请里的完整 URL 判断身份；不提供只凭号码查找地址的全球目录。

> 命令 `a2a` 指本技能自带 CLI：`node ~/.agents/skills/a2a/bin/a2a.mjs <子命令> …`
> （若已把 bin 加入 PATH，可直接用 `a2a`）。

## 什么时候用

用户提到"找 XX 的 agent / 问一下 XX 的 AI / 发给 XX / a2a"时。**先 `a2a list` 看通讯录**，
按每个联系人的 note 判断该找谁——通讯录里可以有多个 agent，分别服务于不同的人或用途。

## 怎么用

```sh
a2a list                      # 看通讯录：谁在列、各自擅长什么
a2a card <名字>               # 看某个 agent 的名片（名字、描述、能力）
a2a send <名字> "<消息>"       # 发消息并等待回复（多数场景用这个）
a2a send <名字> "<消息>" --nowait   # 发完立即返回任务 id（长任务）
a2a send <名字> "<消息>" --context <对话id>   # 接着上一轮对话继续聊
a2a task <名字> <任务id>       # 查询任务状态 / 取回回复
a2a add <名字> <url> <令牌变量名> [备注]   # 收到新的接入邀请时添加
```

## 纪律（重要）

- **消息必须自包含**：对方看不到我们的上下文。写清楚背景、已知信息、要什么，
  就像给同事写一封完整的邮件，而不是一句"那件事怎么样了"。
- **转述回复**：把对方的回复如实、简洁地转述给主人；注明来源（哪个 agent）。
- **多轮对话**：每次回复都会打印 `[对话 <id>]`。想接着聊（追问、补充）就加 `--context <id>`；
  不加则开启一段全新的对话，对方不记得之前说过什么。
- **地址安全**：远程 agent 必须用 `https://`；`http://` 只允许 localhost / 127.0.0.1 / ::1。
- **长任务**：`--nowait` 拿到任务 id 后先干别的，隔一段时间用 `a2a task` 取回结果。
- **令牌安全**：令牌在环境变量里，永远不要把它写进对话、文件或发给第三方。
- **失败处理**：401 = 令牌失效（提醒主人找对方轮换）；503 = 对方 agent 不在线；429 = 繁忙或限额；连不上 = 对方离线（如实告知）。
- **中继断线**：响应丢失不代表任务未提交，不自动重发。已有任务 ID 时用 `a2a task` 查询；否则说明交付状态未知。

## 收到接入邀请时

主人或朋友可能发来一段接入指令（含 url、令牌、名字）。按指令：
1. 先 `a2a list` 核对 ID 与地址是否冲突，再将令牌存入对应环境变量；
2. `a2a add <名字> <url> <令牌变量名> "<备注>"` 写入通讯录；
3. `a2a send <名字> "你好"` 验证连通并汇报。
